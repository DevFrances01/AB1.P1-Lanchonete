# 🍔 AB1.P1 — Lanchonete

## 📌 Descrição

Exercício desenvolvido em **Java** para calcular o valor final de uma conta em uma lanchonete.

O programa recebe a quantidade de cada produto consumido e calcula o total da conta com base nos preços definidos no exercício.

## 🛠️ Tecnologias

* Java
* `Scanner`
* Variáveis `int` e `double`
* Operações matemáticas
* `System.out.printf()`

## 🍔 Produtos e preços

| Produto      |   Preço |
| ------------ | ------: |
| Hambúrguer   | R$ 3,00 |
| Cheeseburger | R$ 2,50 |
| Fritas       | R$ 2,50 |
| Refrigerante | R$ 1,00 |
| Milkshake    | R$ 3,00 |

## 📥 Entrada

O programa recebe cinco valores inteiros, representando a quantidade de cada produto:

1. Hambúrguer
2. Cheeseburger
3. Fritas
4. Refrigerante
5. Milkshake

## 🧮 Cálculo

O valor total é calculado multiplicando a quantidade de cada produto pelo seu respectivo preço:

```text
Total =
(hambúrguer × 3,00)
+ (cheeseburger × 2,50)
+ (fritas × 2,50)
+ (refrigerante × 1,00)
+ (milkshake × 3,00)
```

## 📤 Saída

Ao final, o programa apresenta o valor total da conta no seguinte formato:

```text
Conta final: 00.00
```

O valor é exibido com **duas casas decimais**.

Praticar:

* Entrada de dados com `Scanner`

* Tipos numéricos
* Multiplicação
* Soma
* Cálculo de valores
* Formatação de saída com `printf`
